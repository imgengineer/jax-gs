# Packed backward：按统计需求省去 warp 投票

2026-10-02，RTX 5090，驱动 615.71.09，JAX/jaxlib 0.11.2、Flax 0.12.10、
Optax 0.2.8、CUTLASS DSL 4.8.0。基线为 `ca365ef`，生产源码与 `64d2b1a` 相同。
本轮使用已有本地文档和原型，没有新增联网查询或依赖。
全部样本、源码补丁、检查结果与复现脚本见 [JSON](warp_vote_20261002.json)。
用户确认 GPU 可独占后，又追加了四组复测，见文末；README 使用追加测量的结果。
这些测量使用按完整 epoch 取整的 30k 配置，实际更新 29,913 次。
当前默认预算为 10k；复现此处完整训练时，请显式设置
`optimization.iterations = 30000`，其余参数沿用记录中的配置。

生产改动只有反向循环中的一个条件：没有收集统计时，不再对每个像素组执行
`vote_any_sync(mask != 0)`。alpha、Gaussian 值和最后处理索引的逐像素遮罩继续生效；
被遮罩的组对普通梯度累加只产生零。贡献位图仍负责跳过完全没有贡献的 Gaussian。
有效组的 half2 累加顺序、前向合成与缓存布局均保留。

收集统计时保留原判断。该路径累加的是各组之后的**部分 opacity 梯度的平方**，
空组不能再次计入已有部分和。新增测试专门覆盖一组产生非零梯度、相邻组没有贡献的情况。

`step=30000` 起、场景半径 1、SH3、Optax、8×16 tile、8M pair 容量。
